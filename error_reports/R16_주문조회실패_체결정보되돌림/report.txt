[제보] NH FUTURES API: 주문내역 조회 실패 뒤 체결 수량과 잔량이 이전 값으로 돌아갑니다

팀: team-09
환경: Windows / Node.js v24.22.1, 2026-11-14 12:29 (KST)
대상: 공개 저장소 NH FUTURES API의 주문목록 처리 (frontend/src/data/account.ts, 버전 3311fb4e82aa)

공개 원본 코드에 가상 조회 응답과 체결 알림을 넣어 재현했습니다. NH 서버 호출과 실제 주문 전송은 없습니다.

재현 절차

1. 아래 링크의 reproduce_R16.zip을 받아 압축을 풀고 RUN_REPRO.cmd 실행 (Node.js 18 이상 필요)
2. 재현 코드에서 미체결 1계약인 주문을 넣고 주문내역 재조회 시작
3. 조회 응답을 받기 전에 체결 알림을 넣어 체결 1계약·잔량 0계약으로 변경
4. 진행 중인 조회에 HTTP 502 반환. 체결 알림으로 예약된 후속 조회에도 HTTP 502 반환

※ 2~4번은 재현 코드가 자동으로 실행합니다.

기대 결과
조회가 실패해도 이미 받은 체결 정보가 유지됨 (체결 1계약·잔량 0계약)

실제 결과

- 체결 알림 직후에는 체결 1계약·잔량 0계약으로 정상 반영됨
- 조회가 실패하면 체결 0계약·잔량 1계약으로 돌아감
- HTTP 502 대신 통신 오류가 발생한 경우에도 같은 현상 발생
- 같은 조건에서 재조회 응답만 HTTP 200으로 바꾸면, 후속 조회가 실패해도 체결 1계약·잔량 0계약 유지

근거 (재현 코드·실행 결과)
https://github.com/kimbluesky/nh-pioneer-team-09/tree/main/error_reports/R16_주문조회실패_체결정보되돌림

- reproduce_R16.zip: 재현 코드와 원본 소스
- result.json: 조회 실패 2가지와 정상 응답 비교 결과

영향
이미 체결된 주문이 주문목록에서 미체결로 남아, 체결 여부와 잔량을 잘못 확인할 수 있음

개선 제안
조회 실패 시에도 조회 중 받은 체결 정보가 유지되도록 오류 처리 수정
