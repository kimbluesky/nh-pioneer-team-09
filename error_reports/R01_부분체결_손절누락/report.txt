[제보] NH FUTURES API 앱: 부분 체결 상태에서 손절선을 지나도 청산 주문이 나오지 않습니다

팀: team-09
환경: Windows / Python 3.12.10, 앱 내 가상 체결(paper), 2026-11-12 21:05:37 KST
대상: 전략 검증 > 부분 체결 상태의 손절 처리 (공개 소스 fbfca3e)

재현 절차
1. Python 실행 환경이 준비된 NH 프로젝트 폴더에 reproduce_R01.zip을 내려받음
2. PowerShell에서 아래 명령 실행
.\.venv\Scripts\python.exe -B reproduce_R01.zip
3. 스크립트가 원본 전략 엔진에 합성 시세를 넣어 시장가 매수 2계약 중 1계약만 101에 체결시킴. 손절은 2틱, 틱 크기는 0.05로 설정
4. 시세를 손절가 100.90보다 낮은 100.85로 내리고, 처음부터 1계약을 주문해 전량 체결한 경우와 청산 주문 생성 여부를 비교

기대 결과
부분 체결 상태에서도 이미 체결된 1계약에는 손절이 적용되어 매도 청산 1계약이 생성돼야 함.

실제 결과
- 2계약 중 1계약만 체결: 손절선을 지나도 청산 주문 0건
- 1계약 주문 후 전량 체결한 대조군: 같은 시세에서 매도 청산 1건 생성
- 두 경우 모두 실제 보유는 매수 1계약이지만, 부분 체결에서는 상태가 ‘진입 주문 중’으로 남아 손절 감시를 건너뜀
- 매도 방향에서도 같은 현상 확인

근거
result.json: 설정, 시세 입력, 주문·체결 결과, 원본 엔진 이벤트
reproduce_R01.zip: 재현 코드와 공개 원본 소스
https://github.com/kimbluesky/nh-pioneer-team-09/tree/main/error_reports/R01_부분체결_손절누락

합성 시세를 이용한 공개 프로그램의 오프라인 재현이며, NH 서버 호출은 하지 않았습니다.

영향
가상 체결에서 이미 보유한 수량에 손절이 적용되지 않아 손실과 전략 검증 결과가 달라질 수 있음.

개선 제안
진입 주문이 부분 체결된 상태에서도 이미 체결된 수량의 손절을 감시하도록 수정 부탁드립니다.
