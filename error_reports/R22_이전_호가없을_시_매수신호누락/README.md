# [제보] NH FUTURES API: OR 조건에 이전 호가 값이 없으면 정상 가격 조건을 충족해도 매수 신호가 누락됩니다

팀: team-09
환경: Python 3.13.5, 오프라인 재현(NH 서버 호출 없음), 2026-11-20 KST
대상: 공개 저장소 NH FUTURES API의 전략 검증 조건식 판정 (backend/strategy/rules.py, 사용자 제공 소스: nh-futures-open-api-main

## 재현 절차
1. reproduce_R22.zip을 준비한 폴더에서 아래 명령을 실행합니다. 압축을 풀 필요는 없습니다.
   py -3.12 -B reproduce_R22.zip --output R22_result.json
2. 동봉한 원본 관련 Python 파일 7개의 SHA-256 무결성을 검사합니다.
3. 매수 진입 규칙을 OR(any) 조건으로 구성합니다.
   - 조건 A: 종가 > 100
   - 조건 B: 매수 1호가 잔량 >= 10계약
4. 과거 봉(10:00)의 종가 99와 현재 봉(10:01)의 종가 101을 넣습니다. 현재 봉의 매수 1호가 잔량은 1계약, 과거 봉의 잔량은 미수신(None)으로 둡니다.
5. 가격 조건만 있을 때, 두 조건을 OR로 묶었을 때, OR로 묶고 과거 호가 잔량을 1로 제공했을 때를 비교합니다. 다른 대조군 3개도 자동 확인합니다.

※ 2~5번은 재현 코드가 자동 수행합니다. 봉·호가·시간은 합성 데이터이며 실제 거래소 응답이 아닙니다. 원본 규칙 함수들을 실행했으며 NH API, 웹소켓, 계좌에 접속하거나 주문을 생성하지 않았습니다.

## 기대 결과
종가 조건은 이전 봉 99(거짓)에서 현재 봉 101(참)로 전이했습니다. OR 규칙은 하나만 참이면 충족되므로, 다른 조건인 이전 호가 잔량이 없어도 가격 조건에 따른 매수 신호가 발생해야 합니다.

## 실제 결과
- 가격 조건만 설정: 매수 진입 신호 발생(봉 인덱스 1)
- OR 조건 + 이전 호가 잔량 미수신: 종가 조건이 참이고 매수 1호가 잔량 조건은 거짓인데 매수 신호 0건
- OR 조건 + 이전 호가 잔량 1계약 제공: 같은 가격, 같은 조건에서 매수 진입 신호 1건 발생
- 호가 조건만 / AND 조건 / 두 조건 모두 거짓 대조군: 매수 신호 0건
- 실제로 rules.step_at은 OR 단계가 참이라고 답하나, rules._unknown_before가 이전 호가 결측을 검출하여 rules.advance가 신호를 차단함
- PASS R22_SOURCE_INTEGRITY (7/7), [BUG REPRODUCED] R22 확인

- result.json: 조건별 현재/이전 참·거짓, 결측 여부, 매수 신호 발생 봉, 대조군 결과

## 영향
여러 매수 조건을 OR로 연결한 전략에서 실행 전 조회 봉에 호가 값이 없는 경우, 최초 실시간 봉에서 정상 가격 전이가 일어나도 진입 신호가 누락될 수 있습니다. 이후 가격이 계속 조건을 만족하면 새로운 거짓→참 전이가 나타날 때까지 해당 신호가 발생하지 않아 전략 검증의 진입 횟수와 성과가 왜곡됩니다.

## 개선 제안
OR 규칙의 한 조건이 독립적으로 거짓→참이 된 것이 확인되면, 다른 조건의 이전 값이 미수신이라는 이유만으로 전체 전이를 차단하지 않도록 변경 부탁드립니다. 결측 검사 시 OR/AND 논리와 확인된 조건의 전이 여부를 구분해 주세요.
