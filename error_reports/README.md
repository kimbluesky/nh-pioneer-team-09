## 재현 자료

각 오류 폴더에는 다음 파일을 올립니다.

- `report.txt`: 재현 절차, 기대·실제 결과, 영향, 개선 제안
- `reproduce_R번호.zip`: 재현 코드, 원본 소스, 실행 설명
- `result.json`: 재현 실행 결과

실행 환경과 방법은 각 폴더의 `report.txt`를 참고해 주세요. 오류마다 실행 방법이 다릅니다.

## 갱신 방법

새 오류를 올릴 때 해당 폴더와 함께 위 표에 번호, 내용, 상태, 자료 링크를 추가합니다. 운영진 답변을 받으면 상태를 갱신합니다.
