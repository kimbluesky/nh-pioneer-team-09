[제보] NH FUTURES API 앱: FOK 주문이 0체결로 취소된 뒤에도 호가 잔량이 차감됩니다

팀: team-09
환경: Windows / Python 3.12.10, 앱 내 가상 체결(paper), 2026-11-12 02:28:12 KST (합성 시세를 이용한 오프라인 검증)
대상: 전략주문 > 전략 검증 > 지정가 FOK 가상 체결 (공개 소스 fbfca3e)

재현 절차
1. Python 실행 환경이 준비된 NH 프로젝트 폴더에 reproduce_R03.zip을 내려받습니다. 압축은 풀지 않아도 됩니다.
2. 해당 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.
.\.venv\Scripts\python.exe -B reproduce_R03.zip
3. 스크립트는 원본 시작 검사를 통과한 설정으로 전략 엔진을 실행합니다. 합성 시세에서 매수 조건이 충족되면 101 지정가 FOK 매수 5계약을 생성합니다.
4. 매도호가 101, 잔량 3계약을 입력하면 첫 주문이 0체결로 취소됩니다. 조건이 해제됐다가 다시 충족되도록 시세를 넣어 동일한 5계약 주문을 생성하고, 같은 가격의 잔량을 5계약으로 늘립니다.

기대 결과
첫 주문은 체결 없이 취소됐으므로 잔량을 차감하지 않아야 합니다.
두 번째 주문은 잔량 5계약에서 전량 체결돼야 합니다.

실제 결과
- 첫 주문: 0체결 취소. 내부에는 3계약을 사용한 것으로 남습니다.
- 두 번째 주문: 표시 잔량이 5계약인데도 0체결 취소됩니다.
- 대조군은 첫 매도호가 가격만 101.05로 바꿔 0체결 취소한 경우입니다. 두 번째 주문·호가는 동일하며 5계약이 정상 체결됩니다.
- 매도 방향에서도 같은 현상을 확인했습니다.

영향
가상 체결에서 잔량이 충분한 주문도 취소돼 진입 내역과 전략 검증 결과가 달라집니다.

개선 제안
