[제보] 공개 프로그램의 해외 일봉 전략이 한국시간 자정에 조기 마감되어 매수 주문을 생성합니다

팀: team-09
환경: NH FUTURES API 공개 소스 3311fb4e / Python 3.13.5, 오프라인 재현(NH 서버 호출 없음), 2026-11-14 KST
대상: NH FUTURES API 프로그램 > 전략 검증 > 해외 일봉·마감 평가 (공개 소스 3311fb4e)
관련 소스: backend/strategy/bars.py, backend/strategy/engine.py

재현 절차:
1. Python 의존성이 준비된 NH 프로젝트 폴더에 `reproduce_R17.zip`을 둡니다.
2. 탐색기 주소 칸에 powershell을 입력하고 Enter를 누릅니다.
3. 아래 명령을 실행합니다. ZIP을 풀 필요는 없습니다.
   `.\.venv\Scripts\python.exe -B reproduce_R17.zip`
4. `PASS R17_SOURCE_INTEGRITY`와 `[BUG REPRODUCED] R17` 및 다음 결과를 확인합니다.
   대조군: 닫힌 일봉 2개, 신규 주문 0건
   자정 통과군: 닫힌 일봉 3개, 매수 시장가 주문 1건(1계약)
   두 체결의 거래일은 모두 2026-11-05이며, 잘못 마감된 일봉의 종가는 0.66입니다.
   `PASS R17_SOURCE_INTEGRITY`는 관련 원본 파일 7개의 SHA-256 무결성 검사가 통과했다는 뜻입니다.
   `[BUG REPRODUCED]`는 오류와 정상 대조 조건이 설명대로 재현됐다는 뜻입니다.
   JSON 결과를 저장하려면 명령 뒤에 `--output R17_result.json`을 붙입니다. 기존 결과 파일은 덮어쓰지 않습니다.

5. 스크립트는 원본 전략 엔진에 합성 일봉과 체결 시세를 입력해 두 경우를 비교합니다.
   - 대조군: 11월 5일 23:59:57(0.66) → 23:59:59(0.67)
   - 재현군: 11월 5일 23:59:59(0.66) → 11월 6일 00:00:01(0.67)

기대 결과:
두 체결은 모두 11월 5일 거래일에 속하며 거래 세션이 종료되지 않았으므로, 자정에 일봉이 마감되거나 신규 주문이 생성되어서는 안 됩니다.

실제 결과:
대조군은 닫힌 일봉 2개, 신규 주문 0건으로 정상 동작했습니다.
반면 재현군은 11월 6일 00:00:01에 종가 0.66인 일봉을 조기 마감하고, 가격 0.67로 새 일봉을 시작했습니다.
이 과정에서 매수 진입 조건을 평가해 시장가 매수 1계약 주문을 생성했습니다.
실제 엔진 이벤트에는 같은 시각에 다음 기록이 남았습니다.
- 매수 진입 규칙이 걸렸습니다
- 진입 주문 중
- buy 1계약 시장가 시장가
결과 JSON의 `wrong_midnight_close`, `premature_order`, `bug_reproduced`는 모두 `true`입니다.

로그·캡처:
- `R17_result.json`: 대조군·재현군의 거래일, 일봉, 주문, 이벤트 결과
- `reproduce_R17.zip`: 재현 코드, README, 원본 무결성 검사
- 터미널의 `PASS R17_SOURCE_INTEGRITY` 및 `[BUG REPRODUCED] R17` 출력 캡처

검증 대상:
공개 원본: PetterChanHyuk/nh-futures-open-api
커밋: `3311fb4e82aad59ef176599a67f21666b07e926c`
https://github.com/PetterChanHyuk/nh-futures-open-api/tree/3311fb4e82aad59ef176599a67f21666b07e926c
원본 RunEngine과 BarBuilder를 사용하며 원본 함수를 수정하거나 주문을 직접 삽입하지 않습니다.
완성 일봉 2개(종가 0.64), 체결 시세, 종목 메타데이터 및 거래시간표만 합성 데이터로 제공합니다.
설정은 해외 CME / 6AZ26 / 일봉 / 마감 / 시장가 / 종가 0.65 초과 시 매수 1계약입니다.
재현용 거래시간은 한국시간 08:00 개장 → 다음 날 07:00 마감이며, 실제 거래소 장운영정보가 아닌 테스트용 시간표입니다.
원본 엔진에 거래일 판정 함수를 연결해 두 체결이 같은 거래일에 속하도록 설정합니다. 매수 신호와 가상 주문은 원본 전략 엔진이 생성합니다.
관련 원본 파일 7개의 SHA-256을 공개 커밋 기준으로 검사하며, 파일이 일치하지 않으면 재현 실행 전에 중단합니다.
앱 화면을 클릭하거나 NH API·웹소켓을 호출한 검증은 아닙니다. 계좌 키·토큰·사용자 설정은 사용하지 않으며, 실제 계좌 주문 및 체결은 발생하지 않습니다.

영향:
해외 거래 세션이 한국시간 자정을 넘어 이어지는 경우, 거래일이 끝나지 않았는데도 일봉이 마감되고 매수·매도 조건이 조기에 평가될 수 있습니다.
이로 인해 전략 검증에서 잘못된 진입 시점과 주문이 발생하여 보유 상태 및 손익 결과가 왜곡될 수 있습니다.

개선 제안:
일봉 집계 과정에서 한국 달력 날짜 대신 종목별 거래일 판정을 사용하도록 수정해 주세요.
같은 거래 세션의 체결은 자정을 넘더라도 하나의 열린 일봉에 누적하고, 실제 거래일 또는 세션 마감 시점에만 일봉 마감 조건을 평가하도록 개선해 주세요.
