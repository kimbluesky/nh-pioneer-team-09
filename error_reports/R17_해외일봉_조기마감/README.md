# [제보] NH FUTURES API 앱: 해외 일봉이 한국시간 자정에 조기 마감되어 매수 주문을 생성합니다

팀: team-09  
환경: Windows / Python 3.12.10, 앱 내 전략 검증(paper), 2026-11-16 KST (합성 시세를 이용한 오프라인 검증)  
대상: 전략주문 > 전략 검증 > 해외 일봉·마감 평가 (공개 소스 3311fb4e)

## 재현 절차
1. Python 실행 환경이 준비된 NH 프로젝트 최상위 폴더에 `reproduce_R17.zip`을 내려받습니다. 압축은 풀지 않아도 됩니다.
2. 해당 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.

   `py -3.12 -B reproduce_R17.zip --output R17_result.json`

3. 스크립트는 관련 원본 Python 파일 7개의 SHA-256을 검사한 뒤 원본 RunEngine과 BarBuilder를 사용해 전략 검증을 수행합니다. 해외 CME / 6AZ26 / 일봉 / 마감 평가 / 종가 0.65 초과 시 시장가 매수 1계약을 설정하고, 종가 0.64인 완성 일봉 2개를 준비합니다.
4. 재현용 거래시간(한국시간 08:00 개장 → 다음 날 07:00 마감)과 거래일 판정 함수를 적용하고 같은 거래일의 합성 체결 2건을 입력합니다.
   - 대조군: 11월 5일 23:59:57(0.66) → 23:59:59(0.67)
   - 오류군: 11월 5일 23:59:59(0.66) → 11월 6일 00:00:01(0.67)

※ 3~4번은 재현 코드가 자동 실행합니다. 두 경우 모두 체결 간격은 2초이며, 거래일은 2026-11-05로 통제합니다. 기존 결과 파일이 있으면 `--output` 뒤에 다른 이름을 지정합니다.

## 기대 결과
두 체결은 같은 거래일에 속하고 세션이 종료되지 않았으므로 한국시간 자정에 일봉을 닫거나 신규 주문을 생성해서는 안 됩니다. 일봉의 마감 평가도 실제 거래일·세션 종료 시점에 이뤄져야 합니다.

## 실제 결과
- 대조군: 닫힌 일봉 2개, 신규 주문 0건.
- 오류군: 11월 6일 00:00:01에 종가 0.66인 일봉이 닫히고, 가격 0.67로 다음 일봉을 시작합니다. 닫힌 일봉은 총 3개로 증가합니다.
- 조기 마감된 종가 0.66이 매수 조건(0.65 초과)을 충족해 매수 신호 1건과 시장가 매수 1계약 가상 주문이 생성됩니다.
- 콘솔에 `PASS R17_SOURCE_INTEGRITY: 7/7`과 `[BUG REPRODUCED] R17`이 출력됩니다.
- 결과 JSON의 `wrong_midnight_close`, `premature_order`, `bug_reproduced`가 모두 `true`입니다.

## 로그·캡처
- `R17_result.json`: 대조군·오류군의 거래일, 일봉, 신호, 주문 및 엔진 이벤트.
- `reproduce_R17.zip`: 재현 코드, `source_manifest.json`, 실행 설명.
- 터미널의 무결성 검사 통과 및 `[BUG REPRODUCED] R17` 출력 캡처.

합성 완성 일봉·체결 시세·종목 메타데이터·거래시간표를 입력합니다. 두 체결이 같은 거래일에 속하도록 재현용 거래일 판정 함수를 연결하지만, 원본 RunEngine·BarBuilder를 수정하거나 가상 주문을 직접 삽입하지 않습니다. 원본 관련 파일 7개의 SHA-256을 검사하며 전체 저장소의 무결성을 보증하는 검사는 아닙니다. NH 서버·웹소켓 호출 및 실제 계좌 주문은 없으며, 가상 주문의 체결까지 검증한 것은 아닙니다.

## 영향
해외 거래 세션이 한국시간 자정을 넘어 이어질 때 일봉이 조기 마감되고 진입 조건이 잘못된 시점에 평가될 수 있습니다. 이로 인해 가상 주문이 생성되어 전략 검증의 주문 시점, 보유 상태 및 손익 결과가 실제 거래일 기준과 달라질 수 있습니다.

## 개선 제안
BarBuilder의 일봉 구간을 한국 달력 날짜가 아닌 종목·세션별 거래일에 맞춰 계산해 주세요. 같은 거래 세션에 속한 체결은 자정을 넘더라도 하나의 열린 일봉에 누적하고, 실제 거래일·세션 종료 시점에만 마감 조건을 평가하도록 수정해 주세요.
