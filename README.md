# NH선물 REST API Pioneer 1기

## 팀 소개

팀명: BE RICH

NH선물 REST API를 활용해 시세 조회와 매매 전략을 구현하고,
투자전략·포트폴리오 분석 및 LLM 기반 자동매매 서비스를 목표합니다.
백테스팅과 모의환경에서의 실행 결과의 차이를 비교, 검증하여
간극을 줄이고 효과적인 전략 생성 환경을 개선할 예정입니다.
